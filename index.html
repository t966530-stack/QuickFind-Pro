Настройки

По умолчанию: до 50 МБ на файл и до 250 МБ суммарно. Большие файлы могут замедлять браузер, особенно на iPhone.

История, избранное, последний отчёт, язык и настройки сохраняются локально в браузере на этом устройстве и для этого адреса сайта. При смене адреса сайта данные автоматически не переносятся. Выбранные файлы нужно добавлять заново после перезагрузки страницы.

Резервная копия

Сохрани историю, избранное, последний отчёт, язык и настройки в один файл. На другом адресе сайта импортируй этот файл, чтобы восстановить данные. Сами выбранные файлы проекта в копию не входят.

Приватность и ограничения

Локальные файлы анализируются в браузере и не отправляются на сервер. Только поиск GitHub обращается к github.com. На iPhone нельзя автоматически просканировать всю папку: нужно выбрать доступные файлы вручную. Веб-версия не может выполнять произвольные команды терминала.
