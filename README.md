# English

## What is QuickFind Pro?

QuickFind Pro is a browser-based developer workspace designed to help developers inspect project files, search source code, identify potential problems, analyze Python syntax, find duplicate files and discover public GitHub repositories from one interface.

It brings together practical project-inspection and code-search tools in a single workspace, without requiring a traditional desktop IDE.

## Main features

### 1. Project File Management
- Select and load project files from your device.
- Review the selected files and project statistics.
- Manage the current file selection.

### 2. Advanced Search
- Search for words, phrases and code fragments inside files.
- Search by filename.
- Use case-sensitive or case-insensitive matching.
- Save useful search queries.

### 3. Source Code Inspection
- Scan selected files for TODO, FIXME, BUG and HACK markers.
- Count detected markers.
- Display matching filenames, line numbers and comment details.
- Review unfinished tasks, known problems and temporary workarounds.

### 4. Python Syntax Analysis
- Check Python source files for syntax errors.
- Display diagnostic information such as error type, line and column.
- Show the relevant code excerpt and available error explanation.
- Syntax checking does not guarantee that code is logically correct or secure.

### 5. Duplicate File Detection
- Compare project files to identify identical content.
- Review duplicate results and organize project files.

### 6. GitHub Repository Discovery
- Search public GitHub repositories by topic or keyword.
- Review repository information and descriptions.
- Open matching repositories on GitHub.

### 7. Favorites and History
- Save useful searches and repositories.
- Review previous activity.
- Export history and project reports where supported.

### 8. Settings and Backup
- Configure available application settings.
- Export and import supported backup data.
- Manage saved application information.

### 9. Bilingual Interface
- Russian interface (RU).
- English interface (EN).
- Switch languages using the application language selector.
- Source code and original filenames remain unchanged when changing the display language.

## Who is it for?

QuickFind Pro is intended for software developers, programmers, students, software testers and people who regularly work with source code and project files.

## Operating model

QuickFind Pro is a browser-based tool. It is designed for project inspection and search, not as a replacement for a complete IDE. It does not automatically fix bugs, rewrite source code, build applications or deploy projects.

## Getting started

1. Open QuickFind Pro in a modern browser.
2. Select project files using the file selection control.
3. Use Search to find text or filenames.
4. Run code inspection to review TODO, FIXME, BUG and HACK markers.
5. Use Python syntax analysis to inspect Python files.
6. Explore duplicate detection and GitHub repository discovery.

## Project goals

Our goal is to make everyday project inspection, code searching and source-code diagnostics easier to access in one convenient workspace.

# Русский

## Что такое QuickFind Pro?

QuickFind Pro — браузерное рабочее пространство разработчика, объединяющее инструменты поиска по файлам и исходному коду, анализа проектов, проверки синтаксиса Python, обнаружения дубликатов и поиска публичных репозиториев GitHub.

Программа помогает быстрее ориентироваться в проектах и находить потенциальные проблемы в коде из единого интерфейса.

## Основные возможности

### 1. Управление файлами проекта
- Выбор и загрузка файлов с устройства.
- Просмотр списка выбранных файлов и статистики проекта.
- Управление текущим набором файлов.

### 2. Расширенный поиск
- Поиск слов, фраз и фрагментов кода внутри файлов.
- Поиск по названиям файлов.
- Поиск с учётом регистра и без него.
- Сохранение полезных поисковых запросов.

### 3. Анализ исходного кода
- Поиск маркеров TODO, FIXME, BUG и HACK.
- Подсчёт обнаруженных маркеров.
- Отображение имён файлов, номеров строк и комментариев.
- Выявление незавершённых задач, отмеченных проблем и временных решений.

### 4. Проверка синтаксиса Python
- Проверка Python-файлов на синтаксические ошибки.
- Отображение типа ошибки, номера строки и столбца.
- Показ соответствующего фрагмента кода и доступного объяснения ошибки.
- Проверка синтаксиса не гарантирует правильность логики программы и её безопасность.

### 5. Поиск дубликатов
- Сравнение файлов проекта.
- Обнаружение файлов с одинаковым содержимым.
- Просмотр результатов для упорядочивания проекта.

### 6. Поиск репозиториев GitHub
- Поиск публичных репозиториев по темам и ключевым словам.
- Просмотр информации и описаний проектов.
- Переход к найденным репозиториям на GitHub.

### 7. Избранное и история
- Сохранение полезных поисковых запросов и репозиториев.
- Просмотр предыдущих действий.
- Экспорт истории и отчётов, если функция поддерживается приложением.

### 8. Настройки и резервные копии
- Настройка доступных параметров приложения.
- Экспорт и импорт поддерживаемых резервных копий.
- Управление сохранёнными данными приложения.

### 9. Два языка интерфейса
- Русский язык (RU).
- Английский язык (EN).
- Переключение языков через переключатель в приложении.
- При смене языка исходный код и оригинальные имена файлов не изменяются.

## Для кого предназначен QuickFind Pro?

Для разработчиков программного обеспечения, программистов, студентов, тестировщиков и всех, кто регулярно работает с исходным кодом и файлами проектов.

## Как начать работу

1. Откройте QuickFind Pro в современном браузере.
2. Выберите файлы проекта на своём устройстве.
3. Используйте поиск по тексту и именам файлов.
4. Запустите анализ кода для поиска TODO, FIXME, BUG и HACK.
5. Проверьте Python-файлы на синтаксические ошибки.
6. Используйте поиск дубликатов и поиск репозиториев GitHub.

## Цель проекта

Наша цель — объединить повседневный поиск по проектам, проверку исходного кода и диагностику в одном удобном рабочем пространстве.
